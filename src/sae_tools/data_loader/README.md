# Data Loader & Adapters

This module provides a unified interface for loading and adapting various safety and jailbreak datasets into a standardized format.

## Usage

```python
from data_loader import get_adapter

# 1. Get the adapter for a specific dataset
adapter = get_adapter("WildGuardTest")

# 2. Load and transform the dataset (supports HuggingFace datasets)
# You can optionally specify a split or subset if the adapter allows
dataset = adapter.load("path/to/dataset", max_samples=100)

# 3. Access unified data
print(dataset[0])

```

## Unified Output Format

All adapters transform data into the following dictionary structure:

```python
{
    "prompt": str,                    # User input
    "response": str,                  # Model response (empty string if unavailable)
    "prompt_label": str | None,       # "Safe" / "Unsafe" / None
    "response_label": str | None,     # "Safe" / "Unsafe" / None
    "category": str,                  # JSON string containing harm types and metadata
    "source": str                     # Dataset source identifier
}

```

### Category Format

The `category` field is a JSON string generated by `make_category`. It uses prefixes to distinguish information:

* **`harm:`**: Indicates specific harm categories (e.g., `{"harm:Violence": 1.0}`).
* **`meta:`**: Indicates metadata or flags (e.g., `{"meta:adversarial": 1.0}`).
* **Values**: Normalized to a float between `0.0` and `1.0`.

## Adding a New Adapter

To add a new dataset:

1. Create a class inheriting from `BaseAdapter`.
2. Implement the `transform(self, example)` method to map raw fields to the unified format.
3. Register the class in `data_loader/adapters/registry.py`.
